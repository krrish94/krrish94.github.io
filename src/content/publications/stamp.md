abstract: STAMP relaxes the hybrid task-and-motion-planning problem into a continuous domain, enabling gradients from differentiable physics simulation to optimize discrete and continuous plan parameters jointly. It uses Stein Variational Gradient Descent and GPU-parallelized simulation to find multiple diverse plans in a single optimization run while substantially improving speed over existing approaches.
